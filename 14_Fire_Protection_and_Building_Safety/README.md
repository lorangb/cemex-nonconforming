## B. Fire codes adopted

Under C.R.S. 32-1-1002(1)(d), a fire district's code applies in unincorporated territory only after the Board of County Commissioners approves it by resolution. Boulder County does not adopt the International Fire Code (IFC) itself (Building Code §101.4.6).

| | Hygiene FPD (covers the main plant parcel) | Lyons FPD |
|---|---|---|
| Edition | **2012 IFC**, adopted by district resolution 6/12/2013 | **2021 IFC** with Appendices B, C, D, F, H and I (district Res. 2023-003; revised as 2023-004 for the county) |
| County / Town approval | **Boulder County Res. 2014-28** (hearing 4/8/2014; adopted 4/10/2014) | Town of Lyons Res. 2023-23 (4/17/2023). BOCC public hearing 6/22/2023 (Docket FCRC-23-0001); the county resolution number was not located. Earlier 2015 IFC: Boulder County Res. 2021-71 (9/16/2021) |
